# 改行クリーナー（Kaigyo Cleaner）

PDF・メール・Web からコピーした文章の余計な改行を削除し、段落を保ったまま読みやすく整形する無料ツール。

- 完全ブラウザ内処理（テキストは外部送信しない）
- 段落保持／箇条書き保持／行末ハイフン結合／空白整理
- 単一 `index.html`（依存なし）。Cloudflare Pages で静的ホスティング

## 開発

`index.html` を編集して push すると Cloudflare Pages が自動デプロイします。

## 姉妹ツール

- 整文クリーナー（話し言葉のケバ取り・整文）: https://seibun-cleaner.pages.dev/
